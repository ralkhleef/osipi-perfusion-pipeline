    Documentation

    This page explains the values in the results. Reference metrics compare a submitted map with the matching reference map. QC and regional statistics describe the submitted map. Validation results are reported separately. The current configuration has no pass/fail thresholds or ranking rules.

    What each thing is compared against

    In the reportCompared againstWhere the comparison happens
    Parameter maps (Ktrans, vp, CBF, ATT …) The ground truth map for the same scan: same participant, site and repeat Voxel by voxel, whole image and inside each region mask
    Fitted signal (4‑D) The measured signal-time curve for the same scan Residual sum of squares per voxel, across time
    ROI statistics Nothing. These describe the submitted map itself Inside each region mask, one row per scan
    Grouped statistics The same quantity across repeats, sites or participants Across scans, which is why they need more than one

    Not available means the value was not calculated. Common reasons are a missing matching reference map or a file that is not a parameter map.

    What the columns mean

    ColumnWhat it means
    BiasMean of (submitted − reference) across the voxels compared. A positive value means the submitted value is higher on average. Opposite errors can cancel, so check the regional rows as well as the whole-image row.
    MAEMean absolute error. The average size of the difference, without its direction.
    RMSERoot mean squared error. This gives more weight to larger differences than MAE.
    Error CoVThe population standard deviation of voxelwise errors divided by the absolute reference mean in the same region. It is a spread-of-error ratio, not a repeatability coefficient of variation. A near-zero reference mean makes the ratio unstable; background can strongly affect whole-image values. A large value is not automatically normal or a failure. Check the region, denominator, bias and absolute errors together. At a zero denominator this ratio is unavailable.
    Corr.Pearson correlation between submitted and reference voxels. Review it together with bias and the error measures.
    Within-scan CoV (ROI tables)Standard deviation divided by mean inside one region of one scan. This describes how variable the map is within a region. It is not a comparison against ground truth and it is not a repeatability measure.
    VoxelsNumber of voxels used after non-finite values were excluded.

    About the 15% figure

    A possible CoV guideline of 15% was discussed, but it was not confirmed as a formal threshold. The current configuration handles it as follows:

    • No challenge currently has a threshold. Reports show “not assessed”.
    • Organisers can set warn_above for a metric in config/validation_rules.yaml. Values above it are marked for review.
    • A flag marks a row for review. It does not change the value or submission order.

    The pipeline applies the 15% figure only if it is added to the configuration.

    Telling one row from another

    In the DCE-2026 layout, Ktrans.nii.gz appears in each scan folder. The file name alone does not identify the scan.

    Every table and CSV therefore carries the scan as its own column, written as P1 · Site 2 · Repeat 1, and the CSV exports lead with separate participant, site and repeat columns so a spreadsheet can sort and filter on them. A row that reads Not identified is one whose folders did not say which scan it came from.

    Items still to confirm

    The configured ICC models are listed below. Other rules and thresholds still need confirmation from the challenge leads.

    • ICC study design. ICC(2,1) and ICC(3,1) are configured separately for DCE, ASL and DSC, using scan-level ROI medians across repeat sessions with site held fixed. These settings still need final approval.
    • Thresholds. This includes the possible 15% guideline above.
    • Methods document. Its required sections and whether it is required.
    • Region definitions. These come from the organiser-provided masks.

    The supplied DCE masks overlap: hippocampus voxels are also included in the grey matter mask. The regional statistics follow those masks as provided, so those two results are not independent.
