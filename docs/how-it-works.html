    How it works

    Indexing

    An archive is extracted once and indexed into a manifest. Each file becomes an artifact record with a role — parameter map, fitted signal or methods document — and a scan identity: dataset, participant, site, repeat.

    Identity is read from the directory structure first; a path such as Synthetic/Participant1/Site1/Repeat1/Ktrans.nii.gz gives all four values. Configured filename patterns fill gaps. Where the two disagree the directory wins and the conflict is reported. Identity is never inferred from file ordering. Reference and mask directories are excluded from the submission's artifacts.

    Validation

    File-level checks cover NIfTI readability, dimensions, finite values, zero-byte files and documentation. Structural completeness checks the submission against its challenge configuration. Errors block the submission; warnings do not.

    Structural codes: REQUIRED_MAP_MISSING, REQUIRED_ARTIFACT_MISSING, MAP_DIMENSION_MISMATCH, ARTIFACT_DIMENSION_MISMATCH, DUPLICATE_PARAMETER_MAP, DUPLICATE_REQUIRED_ARTIFACT, DUPLICATE_METHODS_DOCUMENT, INCOMPLETE_ARTIFACT_IDENTITY, DATASET_COUNT_MISMATCH, IDENTITY_CONFLICT, UNKNOWN_DATASET.

    Execution

    A submission with a Dockerfile runs in a container with a configurable timeout; the command comes from run_config.json inside the submission. Result-only submissions skip this step. If Docker is unavailable the step is disabled and validation and export still work.

    Statistics

    QC reports finite-voxel percentage, NaN and infinity counts, negative-voxel percentage and per-map summary statistics. Parameter types have different units, so they are reported separately and never averaged.

    Where reference maps exist, within-ROI Ktrans statistics are computed: median, population SD (ddof=0) and coefficient of variation (SD ÷ |mean|). These measure the spatial spread of one map in one ROI of one scan — not repeatability, reproducibility or inter-participant variability. Unavailable values are reported as unavailable, not as zero.

    Outputs

    All formats are built from one result, so the numbers are computed once. HTML and PDF contain the same sections, rows and table numbers. Exports are the HTML report, the PDF report, an ROI statistics CSV with one row per scan and ROI, and a combined CSV or JSON in wide or long form.

    Blinded exports omit team name, contact address, submission id and archive name from the body, the metadata and the download filename.
