    Pending scientific requirements

    These items still need a challenge-lead decision. The pipeline does not guess their formulas or present them as official results.

    Official OSIPI challenge ranking is not currently configured. Generic reference comparison and provider-specific analysis are separate capabilities; neither becomes official ranking merely because reference data or a package is present.

    DCE decisions

    • Final definition of one official accuracy metric.
    • Final statistical definition of deviance.
    • Whether signal-time Residual Sum of Squares should remain raw or be normalized.
    • Whether repeat/site variability should be voxelwise, ROI-median based, or both.
    • Whether formal ICC is required and, if so, which ICC model.
    • Final synthetic participant and scan counts, ROI/mask set, thresholds, pass/fail rules, and ranking aggregation.

    Already implemented provisionally: Ktrans ROI median, population SD and CoV; compatible reference-map bias, MAE, RMSE, correlation, error SD/CoV, voxel count and difference maps; conditional measured-versus-modelled 4-D RSS summaries; and descriptive participant/repeat/site grouping. RSS is not labelled deviance, and grouped descriptions are not labelled ICC or formal repeatability.

    ASL decisions

    • Whether ICC is required and which ICC model would apply.
    • Final ASL 4-D fitted-model comparison requirements.
    • Any formal CoV threshold, pass/fail rule, or overall participant ranking.
    • Final ROI/mask set and dataset aggregation rules.

    Already implemented: required CBF/Perfmap and ATT/ATTmap inputs plus compatible whole-image and ROI reference metrics including bias, MAE, RMSE, correlation, error SD/CoV, valid voxel count, and difference NIfTI output.

    DSC decisions

    • Provider-specific scientific metrics, thresholds, reference assets, and any future ranking method.
    • Final ROI and dataset aggregation requirements.

    The current structural rules require CBV, CBF and MTT. Generic QC, previews and compatible generic reference comparisons remain available independently of an official scoring definition.

    Shared handoff decisions

    • Exact required sections in the methods document.
    • Final reference-dataset version names and release policy.
    • Which trusted scoring package, if any, should be designated official by the challenge leads.

    Use the in-app Configuration Manager to test, preview, save and activate structural changes. New scientific formulas still belong in reviewed, tested code or a versioned trusted scoring package.
