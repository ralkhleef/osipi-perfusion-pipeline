    The interface

    The application is one page with six steps down the left. A submission moves through them in order, and each step stays available so you can go back.

    Example output

    A real report, produced by running python3 scripts/demo_evidence.py against a generated DCE submission of 16 scans. Nothing here is mocked up: it is the same code path the Export step uses.

    This is the blinded copy, which is what reviewers see. The team name and contact address are absent and the submission is identified only by number. The scoring columns are empty because the demo runs without reference maps, so the report shows quality control only and says so.
