    The interface

    The application guides each submission through six review stages in order: Upload → Review → Validate → Run → QC & Preview → Export. Select any screenshot to open the full-resolution image.

    Example output

    This is a real example report created from a demo DCE submission with 16 scans. It uses the same pipeline as the Export step.

    The report is blinded, so the team name and contact information are hidden. This demo has no compatible reference maps, so reference-comparison metrics are unavailable for this example.

    • PDF report
    • ROI statistics CSV

    The CSV includes statistics for each scan and ROI, such as the median, standard deviation, CoV, and voxel count.

    You can also generate the HTML, JSON, and unblinded outputs by running the demo locally.
